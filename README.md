# TERVIQA-DEMO

Demo interattiva in italiano per la gestione di una flotta. Puoi consultare il parco mezzi, aprire la scheda di un veicolo, simulare un rifornimento ed esportare l’anagrafica in CSV.

## Prova la demo

Apri [TERVIQA-DEMO](https://zfejzuli1-blip.github.io/TERVIQA-DEMO/). I veicoli iniziali sono fittizi. Usa dati inventati anche per le nuove registrazioni. Le modifiche vengono salvate nel browser con `localStorage`.
